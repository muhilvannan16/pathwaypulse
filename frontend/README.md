# PathwayPulse frontend

React + Vite app. Run it from this folder:

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build    # production build check
npm run lint
```

Right now the app reads **sample data** through `src/api/reports.js`. The full
project README (setup, Supabase, deployment) comes in a later stage.
